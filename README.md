## 💼 Featured Project — ParkNest

**Peer-to-peer parking marketplace (live beta)** · `.NET 8` `ASP.NET Core` `PostgreSQL/PostGIS` `Angular 18` `Flutter` `Docker`

A two-sided marketplace where space owners list driveways and spots, and drivers book them by time window — with an idempotent double-entry credit ledger, optimistic-concurrency booking safeguards, radius search on GiST-indexed PostGIS geography queries, OTP auth with rotating refresh tokens, HMAC-verified payment webhooks, 440+ automated tests, and Prometheus/Grafana observability.
